# Provenance and independence

This is an independently maintained derivative workflow, named **道 · Skill.state** (`dao-skill-state`). It is not the official dao-skill project or the official implementation of the SKILL.state paper. No upstream Git remote, repository history, runtime service or private memory connector is required.

- The root-problem, evidence-level, Trust-gate, conservative evolution and workspace-separation concepts were adapted from [gnipbao/dao-skill](https://github.com/gnipbao/dao-skill), inspected at commit `1cae835995c0ff4d9a33a6fec82cca0a54b7cd05`. Its MIT notice is retained in `LICENSE`. Independence of maintenance does not erase attribution or copyright.
- The authoring layout and progressive-disclosure approach follow the [Agent Skills format](https://agentskills.io/specification) and [official skill-building guidance](https://learn.chatgpt.com/docs/build-skills), checked 2026-09-07. A host validator is not a complete implementation of the open standard. This package's local checker is a bounded lint tool, not a certification.
- The optional state contract is informed by [SKILL.state v3](https://arxiv.org/html/2608.26263v3) and the maintainer's local exploratory experiment. It does not include the paper's runtime or reproduce its benchmark. No benchmark result is a promised product benefit.

New instructions, checker behavior and maintenance decisions are owned by this package's maintainers. Existing source notices remain applicable. Private task records and research archives are deliberately excluded from distribution.
