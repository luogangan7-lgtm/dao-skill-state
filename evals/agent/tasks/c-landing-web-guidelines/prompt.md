Build a landing page for Fernhill, a neighbourhood bakery that sells a weekly bread subscription.
Save it as index.html in the current directory: one file with its CSS inline, no external fonts,
images or scripts, because it must work offline. It should read well on a phone and on a desktop.

Sections: a hero with a "Start a subscription" button; how it works (three steps); this week's
breads (four loaves with prices); pickup locations (two shops with hours); three FAQs; a footer.
